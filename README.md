# PhishGuard - Phishing Awareness Training

## About the Project
PhishGuard is a cybersecurity awareness website designed
to help users identify phishing emails, suspicious links,
and common online scams.

## Features
- Cybersecurity awareness information
- Examples of suspicious messages and links
- Interactive phishing awareness quiz
- Score and result display
- Responsive user interface

## Technologies Used
- HTML5
- CSS3
- JavaScript

## How to Run
1. Download or clone this repository.
2. Open the project folder in VS Code.
3. Open index.html using Live Server.

## Disclaimer
This project is for educational and cybersecurity
awareness purposes only.
